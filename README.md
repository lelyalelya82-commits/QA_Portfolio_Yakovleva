# QA Portfolio Yakovleva

Учебный репозиторий с домашними заданиями и автотестами на Python (pytest).

## Структура проекта
- `lesson_01` — базовые задачи
- `lesson_02` — условные операторы и циклы
- `lesson_03` — функции и тесты
- `lesson_04` — StringUtils и автотесты
- `lesson_05` — задания к 5 уроку

## Как запустить тесты
1. Установите зависимости: `pip install pytest`
2. Запустите тесты: `pytest -v`

## Маркеры
- `pytest -m positive`
- `pytest -m negative`
